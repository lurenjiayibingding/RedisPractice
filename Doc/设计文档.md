# 项目结构
## SimpleRedis:封装Redis操作
1. RedisClient:核心类型，负责转换客户端发送的请求和解析服务端响应的数据
   1. 字段/属性
      1. _host:Redis服务器主机名/域名/Ip地址
      2. _port:Redis服务器端口号
      3. _dbNum:
      4. tcpClient
      5. stream
      6. ConcurrentDictionary<string, Lazy<RedisClient>> redisClients:RedisClient客户端集合
   2. 方法
      1. 构造函数，初始化字段和属性
      2. CreateClientAsync:静态工厂方法，返回RedisClient的一个实例
      3. 连接到Redis服务器，并设通过心跳机制保持tcp连接
      4. 验证用户名和密码（如果有的话）
      5. 断开连接
      6. Dispose:释放非托管资源,并将this从RedisClient集合中移除
      7. TransitionCommand:将来输入的命令转换成RESP协议支持的格式
      8. SendCommandAsync:发送命令
      9.  AnalysisRequest:将Redis响应数据转换成命令结果
2. SimpleStringCommand:简单字符串相关的命令
   1. SetAsync(string key,string valye):异步的发送Set请求
   2. GetAsync<T>(string key):异步的发送Get请求
   3. IncrAsync(string key):异步的发送Incr请求
